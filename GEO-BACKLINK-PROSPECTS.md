# USDF GEO / backlink prospect plan

This is an actionable prospect list, not a claim that any external link exists. No outreach, registration, or directory submission should be made without USDF approval and the destination's editorial requirements.

## First-party and controlled properties

| Prospect | Action | Evidence/requirement |
| --- | --- | --- |
| `github.com/Kanishk0107/usdf` | Keep the repository description and README consistent with the public organization name and verified site URL. | Repository owner approval; this is a project link, not an authority backlink. |
| Google Search Console | Verify the exact production domain and submit `/sitemap.xml`. | DNS or HTML verification by the domain owner. |
| Bing Webmaster Tools | Verify the exact production domain and submit `/sitemap.xml`; consider IndexNow only after deployment. | Account and domain-owner authorization. |
| NGO DARPAN profile | Add the public website URL if the profile permits it. | Confirm the profile belongs to USDF and use only the public, verified organization details. |

## Relevant third-party prospects

| Prospect | Why it is relevant | Ethical route |
| --- | --- | --- |
| Uttarakhand NGO / civil-society directories | Local entity discovery and geographic relevance. | Apply only where USDF meets the directory's criteria; use the exact legal/public name and URL. |
| District or state community-development resource pages | Contextual local relevance. | Request inclusion only if USDF has a real, documented programme or public resource to cite. |
| Education, public-health, digital-literacy and environmental networks | Topic relevance for the six stated focus areas. | Publish or contribute a genuinely useful guide, then request an editorial citation where appropriate. |
| Partner, volunteer, or event organizations | First-hand relationship and corroboration. | Seek a link only after a real collaboration or event; never manufacture a partnership. |

## Suggested linkable assets to build later

- A dated, evidence-backed transparency page with public source documents or registry links after publication review.
- A practical Uttarakhand community resource guide with named sources and a clear update date.
- Original programme updates once an activity has actually happened and publication permissions are documented.

Do not buy links, use automated directory blasts, exchange links at scale, or publish unsupported impact statistics. External citations are earned by useful, verifiable material; they cannot be guaranteed by schema or submissions.
